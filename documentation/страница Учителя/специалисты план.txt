Страница «Специалист» — проектные требования (без кода)
1) Назначение

Детальная карточка специалиста (бывш. «Учителя») для работы с профилем, предметами, расписанием/слотами, бронированиями и отчетностью. Страница доступна ролям Админ (полный доступ) и Специалист (ограниченный доступ к своим данным).

2) Профиль специалиста

Что показать

ФИО, статус (активен/заблокирован), роль (фиксируется как teacher/«Специалист»), верификация.

Режим по умолчанию: online / offline / mixed.

Краткая био, заметки (только для админов).

Контакты: телефон, email, Telegram ID (read-only или редактируемо по правам).

Что сделать

CRUD полей профиля.

История изменений ключевых полей (аудит, см. раздел 7).

Критерии приёмки

Сохранение валидируется (email/телефон, длина био).

Режим по умолчанию влияет на предлагаемый формат при создании слотов.

3) Связанные предметы

Что показать/сделать

Мультивыбор предметов из справочника.

Список текущих предметов + добавление/удаление (CRUD через teacher_subjects).

Отображение предметов влияет на фильтры календаря и бронирований.

Критерии

Нельзя добавить дубликат предмета.

Удаление предмета не ломает уже созданные слоты (слоты остаются со старым subject_id).

4) Календарь и слоты

UI/функции

Режимы: День / Неделя / Месяц.

Drag-select интервала → подтверждение параметров (предмет, формат online/offline, вместимость, статус «доступен»), нарезка слотов.

Клик по слоту: изменить параметры (время, вместимость, статус), скрыть, отменить, удалить.

Массовые операции по выборке (чекбоксы/рамка): скрыть/отменить/изменить вместимость.

Валидации и правила

Исключать пересечения по времени у одного специалиста.

Нельзя создавать слоты в прошлом.

При изменении времени/статуса учитываются существующие брони (предупреждение/блокировка).

Критерии

Drag-select создает корректно нарезанные слоты, шаг = системной длительности.

Массовые операции применяются атомарно (частичные ошибки — с отчётом по элементам).

5) Предварительное планирование (2–3 дня)

Функции

Кнопки: Создать предварительные, Подтвердить все на сегодня, Скрыть неподтвержденные.

Фильтр статусов: available / tentative / hidden / canceled.

Поведение

Предварительные слоты создаются со статусом tentative и пометкой «предварительно».

Подтверждение переводит tentative → available (и, если включено, переводит связанные pending-брони в confirmed).

«Скрыть неподтвержденные» меняет tentative → hidden.

Критерии

Кнопка «Подтвердить все» отображается только при наличии tentative-слотов на выбранный день.

Логика не допускает коллизий (повторное подтверждение безопасно).

6) Брони специалиста

Что показать

Таблица с фильтрами: дата-от/до, статус (pending/confirmed/canceled/…),
предмет.

Поля: дата/время, клиент, контакт, статус, комментарий/примечание, источник (кто создал).

Действия

Просмотр карточки брони; быстрые действия по правам: подтвердить/отменить.

Экспорт

Кнопка Экспорт CSV по текущему фильтру.

Критерии

Экспорт содержит те же столбцы, что и таблица (с локализацией заголовков).

Фильтры применяются и к таблице, и к экспорту.

7) Журнал действий и импорт

Журнал

Лента изменений: кто/когда/что поменял (слоты, профиль, предметы), статус операции (успех/ошибка).

Импорт

Кнопка «Импорт слотов по шаблону» (загрузка файла с интервалами).

Превью импорта: подсчёт создаваемых слотов, детект пересечений, список ошибок.

Критерии

После импорта отображается сводный отчёт (успешно/ошибки).

Записи в журнале формируются для каждой операции (включая массовые).

8) Мини-отчёты/виджеты

Виджеты на странице:

Нагрузка за период: слоты, часы, отмены (по предметам).

Слоты без брони сегодня: быстрый список для обзвона/закрытия.

Быстрые ссылки: «Нагрузка по учителю (PDF/CSV)», «Посещаемость/отмены».

Критерии

Период виджетов переключаемый (сегодня/неделя/произвольный).

Значения на виджетах совпадают с данными отчётных эндпоинтов.

9) Настройки уведомлений

Что сделать

Переключатели: получать напоминания (за N минут), уведомления о новых бронях, об отменах.

Персональные настройки перекрывают системные (если разрешено).

Критерии

Тестовая отправка (кнопка «Проверить уведомление») возвращает статус «доставлено/ошибка».

10) Интеграции (вперёд)

iCal-экспорт расписания специалиста (подписка URL).

Политика поздних отмен (порог, шаблон уведомлений).

Прайс/каталог услуг (когда появится биллинг): цена, длительность, валюта; связь слота с услугой.

11) Доступ и безопасность

Роль Админ: полный доступ.

Роль Специалист: доступ только к своим данным, без доступа к настройкам системы и чужим броням/слотам.

Все опасные действия (удаление/массовые операции) — с подтверждением и журналированием.

12) Нефункциональные требования

Страница открывается ≤ 1.5 с при месячном объёме ≥ 50k слотов.

Массовые операции — асинхронно с прогрессом.

Экспорт CSV — ≤ 10 с для выборки до 10k записей.

13) Навигация и связность

С «Пользователей» для роли «Специалист» — действие «Открыть карточку» → эта страница.

Обратная ссылка «К списку специалистов».

Глубокие ссылки: .../specialists/:id?tab=calendar|bookings|profile.

14) Критерии готовности (DoD)

Все разделы отображаются и работают по правам.

Календарь: создание/редактирование/массовые операции/фильтры — без коллизий.

Предварительное планирование: кнопки выполняют заявленные трансформации статусов.

Экспорт CSV соответствует текущим фильтрам.

Журнал фиксирует все изменения и ошибки.

Локализация рус/англ. для всех заголовков и статусов.
